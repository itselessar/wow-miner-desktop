# Contributing

1. Create a branch from `main`.
2. Keep the application local-first: no telemetry, accounts, remote control, or
   private-key collection.
3. Run `npm run verify` before opening a pull request.
4. Include tests for RPC parsing, settings, or validation changes.
5. Never silently replace the pinned upstream Wownero download or checksum.

Security issues should follow `SECURITY.md`, not a public issue.
